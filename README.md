# dz-catalog-analysis

Консольный отчет по каталогу фильмов стримингового сервиса: статистика,
категоризация, отчеты по жанрам и актерам, топовые позиции. Реализовано на
чистом Python без библиотек анализа данных.

## Запуск

```bash
uv sync
uv run catalog_analysis.py
```

## Проверка стиля

```bash
uv run ruff check .
```
